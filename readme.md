# Flower Shop

This is a responsive web page for a flower shop, created as Assignment 2.

## Description

The Flower Shop is a responsive and visually appealing web application designed to showcase a wide variety of fresh flowers and plants. It features a modern layout with a clean navigation bar, an engaging hero section highlighting the shop's offerings, and a product section displaying various plants with their prices and an "Add to cart" option. The website also includes a section detailing the store's qualities as a trusted source for flower and plant lovers, a deals section highlighting special offers on specific plants, and a subscription form for users to join the newsletter. The design utilizes a combination of Noto Serif and Inter fonts to provide an elegant and readable typography experience, ensuring the site looks great on both desktop and mobile devices.
